**Fix Effort:** Low

## Description

The GitHub advisory for zod lists `< 4.6.6` as vulnerable. It describes unbounded accumulation of validation issues in `$ZodArray` when a very large array fails validation. The lockfiles pin `zod` 3.25.76, which falls inside the listed range, although the described code is part of the v4 core and the application uses the v3 API.

## Evidence

**Advisory evidence:** `CVE-2023-54404` applies to `zod` at installed version `3.25.76`. The advisory is fixed in `4.6.6`.

**Usage analysis:** the advisory's affected API is used in application code. `z.array(z.string())` at server/src/importer.mjs:39 and src/main/importer/smart.ts:39, passed to `zodOutputFormat` and parsed from the model response by `client.messages.parse` (server/src/importer.mjs:54, `max_tokens: 2048`). Entry: authenticated upload of screenshots to the smart-import endpoint -> smartRead (server/src/importer.mjs:51) -> Anthropic response (capped at 2048 tokens) -> zod parse. The user controls the screenshots, not the array parsed; no HTTP request body is passed to zod. This is a prioritization signal from static analysis, not a proof of exploitability or of safety.

## Impact

No attacker-supplied array reaches a zod array schema. The only schema containing an array is `z.array(z.string())` applied to Anthropic model output limited to 2048 output tokens, so memory exhaustion is not demonstrable.

## Contextual CVSS

The only array schema is server/src/importer.mjs:39, fed by model output bounded by `max_tokens: 2048` at server/src/importer.mjs:56, and the server never passes request bodies to zod (JSON bodies are handled with JSON.parse in server/src/index.mjs:37). An attacker therefore cannot supply an array large enough to exhaust memory, so availability impact is set to None.

## Remediation

Upgrade `zod` to 4.6.6 or later when migrating to the v4 API, and confirm that `@anthropic-ai/sdk/helpers/zod` works with the chosen major. No request body is validated by zod in the server, so this is low priority.

## Assumptions

The advisory text refers to v4 code; whether 3.25.76 (which bundles `zod/v4` under a subpath but is imported via the default v3 entry here) is truly affected is unverified. The rating assumes the formal affected range applies.
