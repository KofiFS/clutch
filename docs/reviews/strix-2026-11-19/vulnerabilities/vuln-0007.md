# CVE-2026-34451 in @anthropic-ai/sdk 0.80.0 (memory tool path validation sandbox escape)

**ID:** vuln-0007
**Severity:** INFO
**Found:** 2026-11-19 17:04:35 UTC
**Target:** clutch (root and server package-lock.json)
**Package:** @anthropic-ai/sdk
**Ecosystem:** npm
**Installed Version:** 0.80.0
**Fixed Version:** 0.81.0
**CVE:** CVE-2026-34451
**Advisory CVSS:** 5.4
**Contextual CVSS Vector:** CVSS:3.1/AV:N/AC:H/PR:N/UI:N/S:U/C:N/I:N/A:N
**Fix Effort:** Low

## Description

`@anthropic-ai/sdk` 0.79.0 to 0.80.x has a path validation flaw in its local filesystem memory tool helper that lets a model-directed path escape to sibling directories of the memory root. Fixed in 0.81.0. The version pinned in both lockfiles is 0.80.0.

## Evidence

**Advisory evidence:** `CVE-2026-34451` applies to `@anthropic-ai/sdk` at installed version `0.80.0`. The advisory is fixed in `0.81.0`.

**Usage analysis:** imported by application code; affected API usage unconfirmed. The SDK is imported at src/main/triggers/titler.ts:1, src/main/triggers/vision.ts:1, src/main/importer/smart.ts:1, server/src/vision.mjs:1 and server/src/importer.mjs:1, and only `client.messages.parse` plus `zodOutputFormat` are used (for example server/src/importer.mjs:54). A search for memory tool symbols (`memory`, `betaMemoryTool`, `BetaLocalFilesystem`, `toolRunner`) in src/ and server/src/ returned no hits, so the vulnerable helper is not called. This is a prioritization signal from static analysis, not a proof of exploitability or of safety.

## Impact

None in the current code: the application only uses `client.messages.parse` with structured output and never enables the memory tool, so the vulnerable helper is not executed. Risk appears only if the memory tool is adopted later.

## Contextual CVSS

The vulnerable memory-tool helper is never invoked: all five SDK call sites (src/main/triggers/titler.ts, src/main/triggers/vision.ts, src/main/importer/smart.ts, server/src/vision.mjs, server/src/importer.mjs) only use `messages.parse` with a zod output format, so no source reaches the sink and impacts are set to None. Rating changes if the memory tool is enabled.

## Remediation

Upgrade `@anthropic-ai/sdk` to 0.81.0 or later (0.91.1 or later also resolves CVE-2026-41686) in both package.json files and regenerate both lockfiles.

## Assumptions

Static usage analysis by `rg` over src/ and server/src/ for memory-tool and beta helper symbols found no uses. The same version appears in server/package-lock.json (server), so the same fix applies there.
